# I'm Sorry, Jaanu — Hinglish Magnificent Edition ❤️

A premium, mobile-friendly interactive apology experience written in Hinglish.

## Files
- index.html
- style.css
- script.js

## Highlights
- 12 sequential screens
- Hinglish long-form apology letters
- CSS-only chibi boy
- Promise selection + heart collection game
- Commitment checklist
- Mood / reaction choices
- Interactive sorry meter
- Animated sealed letter
- Future relationship note
- Final secret message + heart burst
- Local progress saving
- No photos, videos or music required

## Run
Open `index.html` in a browser or deploy the three files to GitHub Pages.

## Customize
Search `Jaanu`, `meri jaan`, and the paragraphs in `index.html` to personalize the text. All interactions are in `script.js` and styling is in `style.css`.


## Navigation Fix
This build includes a GitHub Pages/mobile-safe delegated navigation handler for all `data-next` buttons, explicit non-submit button types, and a fix for the final decorative burst element. The sequential unlock logic is preserved.
